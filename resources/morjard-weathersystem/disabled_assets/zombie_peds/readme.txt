=====================================================
  Morjard Weather System — Custom Zombie Peds
=====================================================

How to add your own zombie pedes:
1. Copy the .ydd files (and .ytd files, if applicable) to THIS folder.
2. The files must have the correct model name (e.g., a_m_m_eastsa_02.ydd).
3. Restart the resource: /restart morjard-weathersystem

FiveM automatically streams everything from the stream/ folder —
you don't need to edit fxmanifest.lua!
