1. ZAKLADNI FILOSOFIE
================================================================================

  Styl: Cyberpunk / Glass Morphism / Gaming UI
  Tmave pozadi s prusvitnosti + backdrop blur + neonove akcenty
  Kazdy panel je "skleneny" - pruhledny, rozmazany, s jemnym borderem
  Rohy maji cyberpunk dekorace (L-shaped corners s glow efektem)
  Vsechno ma jemne animace a glow efekty

  }

  .corner-bottom-right {

9. ANIMACE & PRECHODY
================================================================================

  -- Zakladni easings:
  ease-smooth:     cubic-bezier(0.25, 0.1, 0.25, 1)
  ease-bounce:     cubic-bezier(0.34, 1.56, 0.64, 1)
  ease-elastic:    cubic-bezier(0.68, -0.6, 0.32, 1.6)

  -- Durations:
  fast:    100ms   (hover efekty)
  normal:  200ms   (prechody, fade)
  slow:    300ms   (slide, scale)
  slower:  500ms   (velke animace)

  -- Vstupni animace elementu:
  @keyframes slideUp {
    from { opacity: 0; transform: translateY(10px); }
    to   { opacity: 1; transform: translateY(0); }
  }

  -- Zmizeni (fade out se slide):
  @keyframes fadeOut {
    0%   { opacity: 1; transform: translateX(0); }
    70%  { opacity: 0.3; }
    100% { opacity: 0; transform: translateX(-20px); }
  }

  -- Focus/active pulse:
  @keyframes focusPulse {
    0%, 100% {
      box-shadow: 0 4px 30px rgba(0,0,0,0.6),
                  0 0 30px -10px var(--accent),
                  inset 0 0 20px -12px var(--accent);
    }
    50% {
      box-shadow: 0 4px 30px rgba(0,0,0,0.7),
                  0 0 50px -5px var(--accent),
                  inset 0 0 35px -8px var(--accent);
    }
  }

  -- Stagger delay pro seznamy:
  .item:nth-child(1) { animation-delay: 0ms; }
  .item:nth-child(2) { animation-delay: 30ms; }
  .item:nth-child(3) { animation-delay: 60ms; }
  /* ... +30ms pro kazdy dalsi */

14. VLASTNI CSS PROMENNE (KONFIGUROVATELNE)
================================================================================

  Tyto promenne uzivatele muzou menit pres nastaveni:

  --accent:            barva akcentu (hex)
  --accent-rgb:        RGB hodnoty pro rgba()
  --bg-opacity:        pruhlednost pozadi (0-1)
  --blur:              sila backdrop blur (0-20px)
  --radius:            zaobleni rohu (0-24px)
  --rotation:          rotace panelu (-15 az 15deg)
  --skew-x:            horizontalni nakloneni (-10 az 10deg)
  --skew-y:            vertikalni nakloneni (-10 az 10deg)
  --corner-size:       velikost rohovych dekoraci (5-50px)
  --corner-thickness:  tloustka rohu (1-4px)
  --corner-display:    block/none
  --corner-glow:       drop-shadow filter / none
  --animation-duration: 0.3s nebo 0s (vypnute animace)

================================================================================
  POZNAMKY
================================================================================

  - Vzdy testuj na tmavem pozadi (FiveM hra je tmava)
  - Pouzivej rgba() misto hex pro pozadi (pruhlednost!)
  - Backdrop-filter: blur() je narocny na GPU - nepouzivej prilis mnoho vrstev
  - Animace pouzivej strridme - v hre je vykon dulezity
  - Barvy akcentu se muzou menit pres nastaveni - pouzivej var(--accent)
  - Pro FiveM: vsechno je v NUI (CEF browser), takze funguje CSS3 + modern JS
