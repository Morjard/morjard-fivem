# Morjard FiveM

**A complete FiveM roleplay resource suite — standalone resources, one shared framework, one visual design language.**

![Framework](https://img.shields.io/badge/framework-QBCore%20%7C%20Qbox-blue)
![Platform](https://img.shields.io/badge/platform-FiveM-red)
![Design](https://img.shields.io/badge/design-Ember-lightgrey)
![Store](https://img.shields.io/badge/store-coming%20soon-yellow)

</div>

---

Every resource below is maintained in its own repository (source, linked under **Source**) and will ship as its own standalone product on Tebex (linked under **Store**, once published). All of them share one visual design language — **Ember**: a dark, chamfered-corner "tactical glass" UI — and one compatibility layer, so they drop into a QBCore or Qbox server side by side without conflicts.
